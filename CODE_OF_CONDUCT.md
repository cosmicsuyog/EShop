# Community guidelines

Participants are expected to be respectful, constructive, and focused on the work. Critique code and ideas without personal attacks. Harassment, discriminatory behavior, threats, and sharing another person's private information are not acceptable.

If you experience or observe a conduct problem, contact the repository owner through the GitHub profile associated with this repository. No separate enforcement team or private contact address is configured. The owner will review reports and determine an appropriate response; this document does not promise a response time.
